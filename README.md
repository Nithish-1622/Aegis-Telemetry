# Aegis Telemetry

Telemetry generation platform for the Aegis suite.

This repository is the Person 1 system. It publishes Kafka telemetry events only and must remain decoupled from the Person 2 runtime intelligence backend.

## Phase 0 outcome

- Maven multi-module parent project established.
- Module ownership and package boundaries documented.
- Kafka contract boundaries recorded.
- Base package roots created for future implementation work.

See `docs/phase-0-architecture.md` for the working architecture contract.
